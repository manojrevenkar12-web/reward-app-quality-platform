# Runbook: the ticket agent filed a bug

The agent saw more tickets about one flow and symptom than that pair usually gets in six hours.

1. Read ten of the tickets in the cluster yourself. If they are about different things, the reader mislabelled:
   add the case to the reader's tests and close the report.
2. Find the release: the in-app form sends app version and device; look for one version or one maker dominating.
3. Cash-out stuck or coins wrong: page the payments on-call; check `/v1/ledger/check` and the payout provider's status.
4. Reply to the players in the cluster with one message once the cause is known; do not promise payouts the ledger
   does not show.
